
## ✅ Submission Checklist

### Required Items
- [ ] **Kaggle Writeup** (max 250 words)
  - Title, subtitle, thumbnail image
  - Project description
  - Track selection (Health/Accessibility)
  
- [ ] **Video Demo** (max 2 minutes)
  - Publicly accessible (YouTube/Loom)
  - No login required to view
  - Impact shown in first 30 seconds
  
- [ ] **AI Studio App Link**
  - App saved in AI Studio
  - "Publish your app" enabled
  - "Default to full screen" enabled
  - Publicly accessible
